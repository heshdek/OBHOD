# Шаблон промпта для 2D-игры

Скопируй блок ниже, замени всё в [квадратных скобках] и отправь Claude.

```
Сделай 2D-игру «НАЗВАНИЕ» — [жанр, например раннер / платформер / аркада] про [тема, место, персонаж].

ТЕХНИКА
- Чистый HTML + CSS + JavaScript, без библиотек и интернета. Офлайн.
- Структура: index.html, js/ (по модулям: config, storage, input, entities, game, ui, audio), assets/ (PNG), audio/ (можно пустая, если звуки через Web Audio).
- Canvas 2D, адаптация под портрет и альбом, 60 FPS. Учти safe-area на телефоне.
- Управление: [тап / клик / пробел / стрелки / свайп], долгое нажатие = [что].
- Рекорд и прогресс в localStorage, обёрнуто в try/catch.
- Звуки через Web Audio API, кнопка выключения звука.

ГРАФИКА
- Все картинки из PNG в assets/ с точными именами (список ниже). Если файла нет — рисуй заглушку кодом, чтобы игра всё равно запускалась.
- Персонаж: [спрайт-лист: имя файла, размер кадра, число кадров, сетка, прозрачность].
- Фон: [слои с параллаксом: имя файла и скорость каждого слоя].
- Смена времени суток: [если нужна], плавно, каждые N секунд.
- Логотип [имя] в углу на всех экранах.

ИГРОВОЙ ПРОЦЕСС
- [Скорость: стартовая, максимальная, как растёт.]
- Препятствия: [список с размерами хитбоксов].
- Предметы и очки: [список, бонусы за серию].
- [Шкала, жизни, что происходит при ударе, неуязвимость.]

ЭКРАНЫ
- Меню, пауза, конец игры (расстояние, монеты, рекорд, кнопка «Заново»), рекорды.
- Язык интерфейса: [язык], с русской подсказкой мелким шрифтом.

ПРОВЕРКА (обязательно)
- Запусти в Chromium: ПК, телефон портрет, телефон альбом. Нет ошибок в консоли.
- Персонаж не уходит за край экрана ни в одном режиме.
- Прогони автотест: для каждого препятствия проверь, что есть окно нажатия, и что без нажатия столкновение происходит.
- Скриншоты всех экранов и состояний, пришли их мне.
- В конце дай список всех PNG: имя, размер в пикселях, нужен ли прозрачный фон.
```

## Короткая версия для запоминания

> Сделай игру по шаблону TEMPLATE_GAME.md: [название и тема].

Claude откроет файл в репозитории и сделает всё по списку.
